# Lokalisierung

Ein Visual-Studio-Projekt zur Umsetzung der Lokalisierung und Mehrsprachigkeit innerhalb einer grafischen Benutzeroberfläche.

## Beschreibung

Das Projekt **Lokalisierung** beschäftigt sich mit der Anpassung einer Anwendung an unterschiedliche Sprachen und regionale Einstellungen. Ziel ist es, Benutzeroberflächen sprachabhängig darzustellen und die Grundlagen der Lokalisierung in .NET-Anwendungen zu verstehen.

## Funktionen

- Unterstützung unterschiedlicher Spracheinstellungen
- Anpassung von Oberflächentexten an die gewählte Sprache
- Verwendung sprachabhängiger Ressourcen
- Integration der Lokalisierung in eine grafische Benutzeroberfläche

## Technologien

- Microsoft Visual Studio
- .NET
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/Lokalisierung.git
   ```

2. Die Datei `Lokalisierung.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.

## Ziel

Das Projekt dient dem Verständnis der Lokalisierung von Softwareanwendungen und zeigt, wie Benutzeroberflächen für unterschiedliche Sprachen und regionale Anforderungen vorbereitet werden können.
